Euler Circuit vs Euler Path
Euler Circuit: A path that starts and ends at the same vertex and uses every edge exactly once.

Euler Path: A path that uses every edge exactly once but does not necessarily start and end at the same vertex.

Eulerize: repeat some links in a way that makes all degrees even, so that we can find an Euler Circuit. 

Handshake theorem: The sum of the degrees of all vertices in a graph is equal to twice the number of edges.
